# nebenk

«Nebeng across all your devices.»

NEBENK is an experimental distributed application runtime designed to let applications run across different devices and survive individual device failures.

Concept

Instead of relying on one permanent machine:

Application
     │
     ├── Phone
     ├── Laptop
     ├── PC
     └── Server

NEBENK aims to let available devices participate in running and maintaining the same application.

Status

🚧 Pre-implementation

NEBENK is currently in the design stage.

Vision

- Device-agnostic
- Lightweight
- Peer-to-peer
- Replicated state
- Dynamic device participation
- Portable application execution

«The application survives. The device is disposable.»
